# 集团IT信息安全、终端准入与密码管理规范

## 第一章：员工终端安全准入与防病毒规范
为了保障集团内部局域网的安全，防范勒索病毒及恶意木马对核心服务器的攻击，所有员工入职时领取的笔记本电脑或台式机，必须在第一时间由IT支持部统一安装‘EDR终端安全管理客户端’并保持24小时常驻运行。严禁员工私自卸载、禁用或通过技术手段修改EDR软件的系统配置，任何终端若离线超过48小时，IT安全监测中心将自动封禁该MAC地址的局域网访问权限。员工在日常办公中，不得将私人移动硬盘、未经杀毒安全扫描的U盘直接插入办公电脑，若确因业务需求需要拷贝大容量敏感数据，必须向部门主管提交‘移动介质临时授权申请表’，审批通过后使用IT部下发的加密安全U盘进行操作。此外，办公电脑禁止安装任何未经合规部授权的盗版软件、游戏软件及非官方授权的P2P下载工具，避免软件后门导致商业机密泄露。

## 第二章：强密码策略、多因子认证（MFA）与锁定机制
### 2.1 域账号密码复杂度要求
集团所有员工的域账号（包含OA、企业邮箱、Gitlab、VPN、财务共享系统等）必须启用强密码策略。密码长度不得少于12位，且必须同时包含大写字母、小写字母、阿拉伯数字以及特殊字符（如@、#、$、%等），严禁使用与用户名、工号、生日、电话号码或连续数字相关的弱密码。系统每90天会强制提醒员工修改密码，且新密码在5次轮转内不得与历史曾用密码重复。如果员工在5分钟内连续输入错误密码达到5次，该域账号将被系统底层自动锁定30分钟，若需提前解锁，必须由本人手持工牌至IT服务台或通过企业微信‘IT小助手’刷脸进行人工实名解锁。

### 2.2 VPN与关键系统多因子认证（MFA）
针对所有远程办公场景，员工通过VPN接入集团内网时，除输入账号和强密码外，必须强制通过‘谷歌身份验证器（Google Authenticator）’或企业微信扫码完成二次动态多因子认证（MFA）。在访问财务报销后台、核心客户CRM系统、以及代码发布中心等S级关键业务系统时，系统会在执行敏感操作前进行二次动态短消息验证或人脸识别，确保操作者为账号所有人本身，杜绝因账号密码泄露导致的黑客入侵。IT安全审计团队每季度会对全集团进行一次钓鱼邮件演练，凡在演练中点击钓鱼链接并未及时上报的员工，将被强制要求参加为期2课时的信息安全线上补课及考核。
