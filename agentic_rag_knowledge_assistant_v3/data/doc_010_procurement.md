# 集团采购、供应商入库管理与付款审批合规流转细则

## 第一章：采购申请（PR）与供应商准入合规审查
为防范商业欺诈、保障集团采购资金的安全高效使用，所有部门因业务需要购买固定资产、软件服务、行政耗材或外包服务时，必须严格遵循‘先审批、后采购’的刚性原则。采购发起人必须首先在采购系统中提交‘采购申请单（Purchase Request, 简称PR）’。针对拟合作的新供应商，必须通过供应商管理委员会（简称供委会）的严格‘合规准入审查’。新供应商需提供包含三证合一营业执照、行业特许资质、近两年经审计的财务报表、以及由企查查等第三方工具导出的无重大失信与法律诉讼记录证明。采购部将组织技术、法律、合规和财务专家对供应商进行多维度的综合打分。评分低于70分或存在严重法律纠纷记录的供应商一律禁止准入。所有供应商必须签署《廉洁合作协议》，严禁向集团任何员工赠送礼品、卡券或提供不正当娱乐活动，一经发现立刻列入黑名单，永不合作。

## 第二章：三方询价比价、采购订单（PO）下发与付款账期流转
### 2.1 三方询价比价与立项审批流
单笔采购金额预计超过5万元人民币（含5万元）的项目，采购部门必须强制执行‘三方比价原则’，即必须获取至少三家无关联关系、具备同等资质的合规供应商的书面正式报价单，并制作《多维度比价分析矩阵表》。在报价、技术指标、交付工期、售后服务保障等维度进行加权打分，原则上优先选择得分最高且价格最优的‘性价比最优方案’。若因特定技术垄断或原厂指定需要进行独家采购的，必须在立项单中详细阐明‘单一来源采购说明’，并由业务分管副总裁（VP）和集团CFO共同签字特批后方可走特殊审批流。

### 2.2 采购订单（PO）签署与财务付款账期控制
PR审批通过且供应商确定后，采购部将在系统内正式生成并下发‘采购订单（Purchase Order, 简称PO）’，PO是集团向供应商发起采购的唯一合法合规要约。供应商必须凭加盖集团公章的PO进行生产和交付。交付完成后，业务部门和质量控制部共同出具《验收合格报告》或《服务交付签收单》。在付款环节，集团严格执行收付实现制和规范的财务账期。标准付款账期为：自收到供应商开具的真实、合法、有效的增值税专用发票且《验收报告》在系统内审批流转完毕之日起算，‘15个工作日’内安排付款；针对外包服务和工程类大额采购，付款账期则严格执行‘收到发票后60天（Net 60）’的延期支付标准，以平滑集团每季度的现金流表现。严禁任何部门以任何借口向供应商承诺‘款到发货’等不合规条款，所有付款流转必须经过财务共享中心的自动化合规机审与人工审计抽查。
