# 上海时长宁区江苏路街道区域划分与历史风貌地理志（详编版）

## 第一章：行政管辖与地理边界划分
江苏路街道是中国上海市长宁区下辖的一个街道办事处，位于长宁区最东部核心腹地，是长宁区对接静安区与徐汇区的传统桥头堡和交通枢纽。其具体的地理四至边界在市民政局与规划局的官方档案中极其明确：东到镇宁路并直接接邻静安区的静安寺街道，北到武定西路并越过苏州河支流接邻静安区的曹家渡街道，南到华山路传统高尚住宅区接邻徐汇区的湖南路街道，西部的界限则相对复杂，主要由长宁路、安西路、武夷路等数条纵横交错的次干道合围而成。整个辖区总面积为1.52平方公里，常住户籍人口达5.26万人，区域内人口密度极高。目前，长宁区区政府的行政总部正设在该街道辖区内的愚园路（近安西路口），这也使得该区域成为了全区的政治、经济与文化活动中心。为了提升政府办事效率，街道办事处在延安西路专门设立了综合社区生活服务中心，提供一站式户政、社保、医保办理服务。

## 第二章：历史文化风貌区与越界筑路建筑
江苏路街道的主要核心干道包括江苏路、愚园路、长宁路、武夷路、武定西路、延安西路等。这些道路在历史上均为上海公共租界越界筑路时期开辟的街区，因此沿线留存了极其大体量的西式花园洋房、新式里弄建筑群。这里目前是上海市重点保护的‘愚园路历史文化风貌区’的主体和核心部分，保存了完好的上海近现代都市生活肌理。区域内较著名的近代优秀历史建筑数不胜数：包括著名的中西女中（即现在的上海市第三女子中学，宋氏三姐妹的共同母校，校园内的五四楼和纪念堂属于国家级受保护文物）、王伯群及汪精卫伪政权公馆（现已改建为长宁区少年宫，其哥特式城堡建筑对公众定期开放）、以及老上海地标性的西园公寓、歧山村、布政司随从旧居、钱学森旧居等。

## 第三章：基层社区治理与居委会细分名录
为了保障超大城市基层社区治理的高效稳健运转，解决高密度老旧小区多、居民诉求多元化的痛点，江苏路街道下辖了13个建制完善的居民委员会（简称居委会）。13个居委会的官方准确名称依次为：歧山居民委员会、江苏居民委员会、万村居民委员会、南汪居民委员会、东浜居民委员会、愚三居民委员会、曹家堰居民委员会、西浜居民委员会、福世居民委员会、长新居民委员会、华山居民委员会、利西居民委员会、北汪居民委员会。其中，歧山居委会因辖区内拥有大量受保护的历史名人故居，成为了全上海弄堂基层精细化治理和红色文化传承的标杆示范点。上海市轨道交通二号线与十一号线的大型换乘枢纽正深埋于该街道辖区地下，设有江苏路站。
