# 集团人力资源管理制度之员工请假、考勤与假期结转细则

## 第一章：日常考勤、打卡与迟到早退处理
为维护良好的工作秩序，集团实行弹性工作制与固定打卡相结合的考勤管理模式。标准工作时间为周一至周五上午9:00至下午18:00，其中中午12:00至13:00为午餐及午休时间。员工每日上下班必须通过企业微信‘考勤打卡’功能在公司办公区域的WiFi定位范围内完成两次打卡。因公外出无法及时打卡的，必须在当日18:00前在OA系统发起‘外勤签到申请’并附加定位截图与拜访客户合影。凡无故未打卡且未发起补卡申请的，一律按旷工半天处理。每个自然月内，因交通拥堵、天气恶劣等不可抗力因素导致的3次以内、每次不超过15分钟的迟到，系统将予以自动免罚免签；超过3次以上的迟到，每次扣减基本工资50元；单次迟到超过2小时且未请假的，视为旷工半天，旷工期间不予发放当日基本薪资。

## 第二章：各类法定假期申请、证明材料与年假结转
### 2.1 事假、病假及法定特殊假期管理
员工因个人私事需要请假的，必须提前至少1个工作日在OA系统中提交‘事假申请单’，事假期间为无薪假，按日扣除基本薪资。请病假的员工，必须在病休结束返回工作岗位的首个工作日内，在系统中上传国家二级及以上公立医院出具的挂号单、病历卡以及正式盖章的‘医学诊断证明书（假条）’。病假期间的工资发放标准按照当地最低工资标准的80%与员工基本薪资的60%孰高原则执行，年度累计病假超过30天的将触发医疗期管理流程。婚假、产假、陪产假、丧假等法定假期，均需凭结婚证、生育服务证、出生医学证明、死亡证明等相关真实合法的纸质材料原件至HRBP处进行备案验真，审批通过后方可享受全薪休假，未备案者按事假处理。

### 2.2 带薪年休假（年假）结转与作废红线
员工累计工作已满1年不满10年的，年休假5天；已满10年不满20年的，年休假10天；已满20年的，年休假15天。此外，集团根据员工入职工龄额外赠予1-5天的‘福利年假’。所有当年未消费完毕的法定年假和福利年假，最迟可自动结转延长至次年的6月30日进行消费。如果在次年6月30日24:00前仍未消费完毕，系统将在7月1日凌晨自动进行‘清零作废’处理，且不予进行任何形式的经济补偿。HR部门会提前两个月在每月考勤看板中对拥有剩余年假的员工进行黄色预警提示，以便各部门负责人合理安排员工的轮流休假计划，确保业务连续性与员工身心健康的双重平衡。
