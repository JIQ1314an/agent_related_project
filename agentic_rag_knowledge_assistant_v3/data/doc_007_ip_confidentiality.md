# 企业知识产权保护、商业秘密保密与竞业限制合规协议

## 第一章：商业秘密定义、密级划分与泄密界定
为保障集团在行业内的技术优势与商业竞争力，所有在职及离职员工均需严格遵守《保密协议》之各项约定。本协议所指的‘商业秘密’包括但不限于：未公开的源代码、系统架构设计图、算法模型参数、核心客户名册及联系方式、未公开的财务报表、战略并购计划、以及采购供应链价格底线等。集团内部数据实行分级分类保护，密级由低到高划分为：‘公开（Public）’、‘内部公开（Internal）’、‘秘密（Confidential）’和‘机密（Strictly Confidential）’。凡密级为秘密及以上的电子文档，必须加盖系统动态水印，严禁通过个人微信、钉钉、私人邮箱等非安全渠道发送或存储至私人云盘。任何员工未经合规部书面特批，将带有水印或涉密的代码段、客户清单拷贝至个人设备，或在外部技术沙龙中公开分享，均被界定为‘严重泄密行为’，集团将依法追究其侵权责任。

## 第二章：职务发明、专利申请权归属与离职交接红线
### 2.1 职务发明与知识产权归属
员工在履行本职工作、或主要利用集团的物质技术条件、设备、未公开数据所完成的各项发明创造、软件著作权、外观设计以及技术诀窍（Know-How），均属于‘职务发明’。该职务发明的专利申请权、软件著作权登记权以及最终的所有权均无条件归集团独立所有，员工享有法定的署名权和获得一次性发明奖励及后续商业转化提成的权利。员工在离职前，必须配合技术管理委员会将所有由其主导或参与的代码仓库（Gitlab Repositories）的所有权和管理员权限完整移交，严禁在个人本地私自留存备份，更不得在离职后将该技术申请为个人或新公司的专利。

### 2.2 离职脱密期与竞业限制条款
针对接触到核心商业机密的高级管理人员及S级技术专家，集团在劳动合同中嵌入了‘脱密期’与‘竞业限制’条款。离职前需执行为期30天的脱密期管理，期间调离核心敏感岗位，停用关键系统权限。自正式离职之日起12个月内，竞业限制人员不得直接入职与集团存在直接竞争关系的同行企业（包括竞争对手名录中的所有关联子公司、合资公司），亦不得自办与集团业务相冲突的公司。在竞业限制期间，集团将按月向离职员工发放相当于其离职前十二个月平均基本月薪‘30%’的竞业限制经济补偿金。若员工违反竞业限制约定，需一次性向集团返还已发放的全部补偿金，并赔偿相当于其离职前年薪总额两倍的违约金，情节严重者将面临刑事侵权诉讼。
