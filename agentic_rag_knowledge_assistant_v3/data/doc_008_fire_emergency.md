# 集团办公大楼消防安全、防灾减灾与应急疏散预案

## 第一章：消防设施分布、日常维保与责任划分
安全保障是企业行稳致远的基石。集团总部办公大楼严格按照国家一级消防安全标准建设，全楼配备了先进的智能烟感温感报警系统、自动喷淋灭火系统、消火栓及干粉二氧化碳灭火器。办公大楼内的消防安全由EHS（环境健康安全）部统一统筹管理。各楼层设立‘义务消防安全员（Fire Warden）’制度，由各部门推荐的主管担任，负责每日闭店前对本区域的电气设备断电情况、消防通道是否畅通、防火门是否处于常闭状态进行例行安全检查，并填报《每日消防安全巡检电子表单》。严禁任何员工在安全通道、步行楼梯间内堆放办公杂物、废旧纸箱或停放电动自行车，所有安全出口指示牌及应急照明灯必须保持24小时常亮，损坏的消防设施必须在2小时内由物业维保部进行强制更换。

## 第二章：火灾应急疏散、逃生流线与灭火器操作规范
### 2.1 应急广播触发与逃生疏散流线
一旦大楼内任意区域烟感器连续10秒监测到烟雾浓度超标，或喷淋头启动，大楼消防控制室将自动拉响消防警报，并触发全楼中英文双语应急疏散广播。听到警报后，全楼员工必须立刻放下手头工作，在各楼层义务消防安全员的引导和指挥下，按照墙面粘贴的《消防疏散示意图》，沿着最近的步行安全通道（安全楼梯A口和B口）迅速、有序、弯腰下楼撤离。严禁在火灾发生时乘坐任何垂直客梯或货梯，避免因大楼突然切断动力电源导致电梯停滞被困。所有人撤离至一楼大厅外，必须迅速前往大楼东侧的安全集结广场（即喷泉广场），各部门主管需立即清点人数，并在5分钟内将应到与实到人数汇总报告给现场应急总指挥，严禁擅自脱队或逆向折返寻找私人财物。

### 2.2 消防器材（灭火器、消防栓）标准操作口诀
为了确保员工在火灾初起阶段具备自救互救能力，EHS部要求全员必须牢记干粉灭火器操作的‘提、拔、握、压’四字口诀：一提，提起灭火器提把；二拔，拔掉保险销；三握，握住喷洒软管前端喷嘴，对准火焰根部；四压，压下压把进行扫射灭火。使用二氧化碳灭火器时，切记不可直接用手握住金属喷管，防止由于低温导致皮肤深度冻伤。若火势较大无法控制，应立即放弃自主灭火，迅速撤离并拨打火警电话119。集团每年于11月9日‘全国消防日’组织全员进行无预警防灾疏散大演习，演习成绩将纳入大楼年度物业管理及行政考核白皮书。
